# Blackthorn OS master-plan specifications

Zack's planning specifications, kept verbatim as the source for docs/design/MASTER_PLAN.md. Received 2026-10-24.
They are planning inputs, not authorizations to build: each one asks for an integrated architecture and gap
analysis before implementation, and none of them is to be implemented alone.

| File | Specification | Authority for |
|---|---|---|
| [TAGS_BADGES_ARCHETYPES_QUALIFICATIONS.md](TAGS_BADGES_ARCHETYPES_QUALIFICATIONS.md) | Tags, Badges, Archetypes & Qualification Engine | recognition: tags, badges, archetypes, qualifications, benchmark collections |
| [POKE_BALLS_EQUIPMENT.md](POKE_BALLS_EQUIPMENT.md) | Poké Ball & Equipment System (approved design direction) | balls, Apricorns, trainer equipment, ball artwork, ball assignment |
| [BUILDER_UI_AND_INFORMATION_ARCHITECTURE.md](BUILDER_UI_AND_INFORMATION_ARCHITECTURE.md) | Self-explanatory builder and the five spaces | inline mechanic explanations, information architecture, record provenance |
| [BREEDING_INHERITANCE_ECOLOGY.md](BREEDING_INHERITANCE_ECOLOGY.md) | Breeding, Inheritance & Ecological Specialization | breeding stock, inheritance legality, lineage, ecological interpretation |
| [SURVIVAL_HOMESTEAD_WORLD_CAPABILITY.md](SURVIVAL_HOMESTEAD_WORLD_CAPABILITY.md) | Survival, Homestead & World Capability Systems | capability framework, expeditions, field readiness, the compound |
| [TRAINER_ECOSYSTEM.md](TRAINER_ECOSYSTEM.md) | Trainer Ecosystem & Benchmark Database | trainer identities, versions, tendencies, playbooks, benchmark collections |
| [INDIVIDUAL_POKEMON_EXPERIENCE.md](INDIVIDUAL_POKEMON_EXPERIENCE.md) | Individual Pokémon Experience & Visual Identity | individuals, builds and versions, profiles, artwork, image packets, Chronicle |

Specifications these documents refer to that have not been supplied yet: **Team Construction**, **Battle
Simulation** (including the 6v6 engine and normalization policy), **Pokémon Biology**, **Reference Database**,
**Technical Architecture**, and the compound-design specification the Homestead section mentions. Where the plan
needs a decision those documents would make, it says so and marks the assumption as provisional.
