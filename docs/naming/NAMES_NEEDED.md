# Names still needed

Every word the build-name ladder uses, and how many current builds use it. Fill a word in `engine/trainers/team_roles.json` → `naming.words.<slot>.<id>`; until then the name shows ⟨what it means⟩. Then `python3 -I engine/trainers/team_roles.py --words` puts the words into every stored read in seconds (no fights), and `python3 -I engine/rebuild.py --only app` shows them in the app. Generated by `python3 -I engine/trainers/team_roles.py --pack`.
